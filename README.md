I'm a software developer with experience in the analysis, design, development, testing, and deployment of enterprise systems, RESTful/GraphQL APIs, and modern web applications. I apply Clean Architecture principles, Domain-Driven Design (DDD), and software design best practices.

I'm passionate about software architecture, performance, security, and writing clean, maintainable code.

### 📌 Featured Projects

#### 🔸 [Social-media APP](https://github.com/OscarS05/social-media-APP)
>  Social media APP built with NestJS and TypeScript, applying DDD and Hexagonal Architecture, Next.js with React in the frontend. Features secure authentication with JWT and OAuth2.0 (Google/Facebook), multi-device session support, social relationships (followers, following), real-time chat with Socket.io (WebSockets), posts, likes, and comments. Deployed on GCP with automated unit, integration, and E2E tests using Jest and Supertest.

#### 🔹 [Trello-like API](https://github.com/OscarS05/Trello-like-project-api)
> RESTful API for collaborative project management inspired by Trello. Features hierarchical roles and permissions, JWT authentication, persistent sessions with Redis, and background task automation (email delivery, file uploads) using BullMQ — reducing processing time by 60%. Built with Node.js, Express, PostgreSQL, SequelizeORM, Docker, and Clean Architecture. Includes unit and E2E tests with Jest and Supertest.

#### 🔹 [Agroplus API](https://github.com/OscarS05/Agroplus-api)
> RESTful and GraphQL API for livestock management, covering animal registration, lineage tracking, vaccination history, deworming records, and custom notes. Built with Node.js, Express, SequelizeORM, PostgreSQL, and Docker following the MVC pattern. Includes automated unit and E2E tests with Jest and Supertest.

#### 🔸 [Blog - Laravel](https://github.com/OscarS05/blog-laravel)
> A question and answer forum built with Laravel and Livewire. Allows users to register, create questions, reply, comment, react, edit, and delete their content.
